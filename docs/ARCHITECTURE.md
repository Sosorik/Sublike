# 아키텍처

## 씬 구조

**사용자가 Godot 에디터에서 직접 만든다. Claude는 .gd 스크립트만 작성한다.**

```
Main (Node)
├── GameState   (autoload)   진행도, 해금 목록
├── DataLoader  (autoload)   JSON 로드/캐시
├── ObjectPool  (autoload)   적/투사체/이펙트 풀
│
├── Lobby
│   ├── SegmentSelect        구간 선택
│   ├── PartyEdit            손패 편성 (해금 가신 중 8명 선택)
│   ├── SkillEquip           아이다 슬롯 3개 장착
│   └── SummonUI             가챠
│
└── Battle
    ├── Aida                 좌측 고정. 이동 없음
    ├── RunState             층 진행, 난이도, 런 강화
    ├── DeployField          배치 타일 9칸 (레인3 × 열3)
    │   └── Tile x9          지상 6 / 고지 3. 배치·철수 입력을 받는다
    ├── Party                손패 8명, DP, 배치/철수 관리
    ├── Units (Node2D)       배치된 가신. 타일 좌표에 고정
    ├── EnemySpawner         우측에서 스폰
    ├── Projectiles
    ├── Effects              피해 숫자, 파티클
    ├── CutinLayer           스킬 컷인 / 소환 연출
    └── BattleHUD            아이다 HP, 층/웨이브, DP, 손패, 버튼 3개
```

## 좌표 규약

레퍼런스: **PvZ의 레인 분리** + **명일방주의 배치·저지**.
레인(가로줄)은 PvZ, 열(세로줄)과 지상/고지는 명일방주에서 왔다.

```
화면 1280x720 가로.  적은 오른쪽 → 왼쪽으로만 이동.

            고지      지상      지상              스폰
            열3       열2       열1
y=236  ┄┄┄┄┄▢┄┄┄┄┄┄┄┄▢┄┄┄┄┄┄┄┄▢┄┄┄┄┄┄┄┄┄┄┄┄┄  ←← 적 (레인 A)
y=348  ┄┄┄┄┄▢┄┄┄┄┄┄┄┄▢┄┄┄┄┄┄┄┄▢┄┄┄┄┄┄┄┄┄┄┄┄┄  ←← 적 (레인 B)
y=460  ┄┄┄┄┄▢┄┄┄┄┄┄┄┄▢┄┄┄┄┄┄┄┄▢┄┄┄┄┄┄┄┄┄┄┄┄┄  ←← 적 (레인 C)
 아이다
 x=80        360       520       680          x=1400
```

| 이름 | x | 타일 | 역할 |
|---|---|---|---|
| 아이다 | 80 | — | 고정. 이동 없음. y=348 (가운데 레인) |
| **열1** | **680** | 지상 | 가장 오른쪽. 적을 **먼저 만나 저지** |
| **열2** | **520** | 지상 | 열1이 뚫렸을 때의 2선 |
| **열3** | **360** | 고지 | 원거리 전용. **저지 0** — 근접 적이 지나친다 |

| 레인 | y |
|---|---|
| A | 236 |
| B | 348 |
| C | 460 |

- **적은 x가 감소하는 방향으로만 이동한다.** 경로탐색 없음
- **적은 레인(y)을 바꾸지 않는다.** 스폰된 레인을 따라 직진만 한다
- 적이 x < 120에 도달하면 아이다에게 피해
- 가신은 배치된 타일 좌표에 고정. 이동·방향전환 없음
- 유닛 스프라이트 키는 **약 100px** — 레인 간격 112보다 작아야 겹치지 않는다
- **가신은 레인과 무관하게 사거리(2D 거리) 안의 적을 공격한다.**
  열1이 붙잡아 둔 적을 열2·열3이 레인을 넘어 함께 때린다.
  ← 편성 조합의 재미가 여기서 나온다 (검증 질문 1번)

## 배치 규약 (DP)

**명일방주 그대로.** 상세 수치는 GDD 4.3.

```
손패에서 가신 선택 → 배치 가능한 타일 강조 → 타일 선택 → DP 차감 → 등장
배치된 가신 선택 → 철수 → 현재 코스트의 절반 환급 (내림)
```

- DP는 **초당 1** 자동 회복. 시작 10
- **재배치 코스트 상승**: 1회차 ×1.5, 2회차부터 ×2 (상한 99)
  이게 없으면 "뺐다 넣기" 반복이 최적해가 되어 전략이 붕괴한다
- **근접 가신은 지상 타일에만, 원거리 가신은 고지 타일에만** 배치된다
- 동시 배치 상한(기본 6)은 타일 수(9)보다 낮게 유지한다 — 다 채울 수 없어야 선택이 된다
- 배치·철수는 **전투 중 언제든** 가능하다. 정비 시간을 따로 두지 않는다

## 가신 특성 (traits)

`heroes.json` 의 `traits` 블록이 그대로 `Unit.traits` 로 온다. 코드에 분기를 늘리지 않고
데이터로 역할을 만든다.

| 특성 | 뜻 | 출처 |
|---|---|---|
| `dp_on_kill` | 이 가신이 처치할 때마다 얻는 DP | 명일방주 Vanguard/Charger |
| `refund_full_cost` | 철수 시 절반이 아니라 **원가 전액** 환급 | 명일방주 Vanguard/Charger |

> 재배치로 코스트가 올라도 환급은 **원가** 기준이다. 그래서 선봉은 반복 재배치가 손해지만,
> 한 번 깔았다 빼는 "초반 DP 벌이 → 딜러로 교체" 는 이득이다. 이게 철수의 존재 이유다.

## 처치 귀속

선봉의 DP 보상은 **누가 잡았는가** 를 알아야 준다.

```
DamagePacket.source_hero_id
  → Enemy._killer_id (마지막 직접 타격자)
  → EnemySpawner.enemy_killed(enemy, killer_hero_id)
  → Battle
  → Party.on_enemy_killed()
```

지속피해로 죽으면 속성을 걸어 준 가신이 아니라 **마지막 직접 타격자**가 가져간다
(지속피해 묶음은 `source_hero_id` 가 비어 있다).

## 진군 차단 규칙

**적은 가신에게 막힌다. 타워디펜스형이다.**

```
적 전진 → 같은 레인의 가신과 접촉 → 정지 → 서로 공격
  → 가신 사망 시 적이 다시 전진
  → 그 레인에 가신이 없으면 아이다까지 직진
```

- 저지 중인 적은 이동을 멈추고 그 가신을 공격한다
- 가신 1명이 저지할 수 있는 적 수에는 상한이 있다 (`block_count`, 명일방주의 저지 수)
  상한을 넘은 적은 막히지 않고 지나간다
- **저지 수가 0인 가신(고지)은 근접 적에게 공격받지 않는다.** 적이 그냥 지나간다
  단 원거리 적(사격체)의 투사체는 고지 가신도 맞힌다 (명일방주 동일)
- `taunt_wall` / `guard_wall` 스킬은 **광역 강제 정지**. 상시 저지와 별개다

## 데이터 흐름

```
data/*.json
   ↓ DataLoader (게임 시작 시 1회)
Dictionary 캐시
   ↓ duplicate(true)
HeroInstance / EnemyInstance  ← 런타임 객체
   ↓
전투 시스템
```

**JSON 원본을 직접 수정하지 않는다.** 런타임 수치는 인스턴스에 복사해 쓴다.

## 전투 파이프라인

```
1. Unit.tick(delta)
2. 쿨타임 도달 → 타겟 탐색 (사거리 내 가장 왼쪽 적 = 가장 위협적)
3. 공격 생성 (ObjectPool에서 acquire)
4. 충돌 → DamagePacket 생성
   { base, is_crit, element, source_hero_id }
5. 아이다 버프 적용    (slot 1)
6. 아이다 속성 적용    (slot 2)
7. 런 내 강화 적용
8. Enemy.take_damage(packet)
9. 사망 → 파편 드롭 + ObjectPool.release
```

**모든 데미지는 DamagePacket을 거친다.**
직접 `hp -= damage` 하는 코드를 만들지 않는다.

## 컷인 시스템

```
스킬 발동
  → CutinLayer에 상반신 이미지 슬라이드 인 (0.15s)
  → 대사 텍스트 표시 + 화면 플래시
  → 유지 (0.3s)
  → 슬라이드 아웃 (0.15s)
총 0.6초. 전투는 멈추지 않는다.
```

- 정지 이미지 + Tween만 사용. 애니메이션 프레임 없음
- 연속 발동 시 큐잉 (겹치지 않게)

```
필수 대상: Enemy(100+), Projectile(200+), DamageNumber, HitEffect, ShardPickup

```
