# 현재 단계: Phase 1 — 프로토타입

**기간**: 4~6주
**목표**: 재미 검증. 안 되면 여기서 갈아엎는다.

---

## 검증 질문 (이것만 확인한다)

1. **캐릭터가 바뀌면 플레이가 재밌게 달라지는가?**
2. **버튼 3개가 부담이 아니라 재미인가?**
3. **속성 부여가 화면에서 눈에 띄게 다른가?**

3번이 특히 중요하다. 속성 효과가 안 보이면 버튼을 누를 이유가 없어진다.

---

## 구현 범위

### 포함 ⭕

| 항목 | 수량 | 비고 |
|---|---|---|
| 캐릭터(가신) | 3 | 임시 아트 (색깔 원형이어도 됨) |
| 무기 | 3 | 근접 채찍 / 원거리 직사 / 유도탄 |
| 아이다 스킬 | 3 | 버프 1, 속성 1(화염), 힐 1 — 각 슬롯 1개씩 |
| 층 | 6 | 1구간. 층당 2~3분 |
| 보스 | 1 | 6층 |
| 적 종류 | 3 | 근접 돌진 / 원거리 / 탱커 |
| 런 내 강화 | 8종 | 층 클리어 시 3택 |
| 소환 연출 | 1 | 보스 격파 후 |

### 제외 ❌

- 가챠 시스템 (연출만, 재화 순환 없음)
- 영구 강화 / 마석 파편 경제
- 세이브 / 로드
- 스토리 텍스트, 대사
- 심층도
- 파티 3명 (**프로토타입은 1명 고정**)
- UI 폴리싱, 사운드
- 최종 아트

---

## 작업 순서

각 항목은 **실행 가능한 상태**로 끝내고 다음으로 넘어간다.

### 1주차 — 기반
- [ ] Godot 프로젝트 생성, 디렉토리 구조
- [ ] JSON 데이터 로더 (`scripts/data/data_loader.gd`)
- [ ] 아이다 이동 (가상 조이스틱 + 키보드)
- [ ] 카메라 추적
- [ ] 오브젝트 풀 (`scripts/core/object_pool.gd`)

### 2주차 — 전투 코어
- [ ] 적 스포너 (웨이브, 화면 밖 생성)
- [ ] 적 3종 (직진 AI)
- [ ] 소녀 1명 자동 전투
- [ ] 무기 3종 구현
- [ ] 데미지/체력/사망 처리

### 3주차 — 아이다 스킬
- [ ] 액티브 버튼 3개 UI + 쿨타임 표시
- [ ] 버프 스킬 (파티 공격력 상승)
- [ ] 속성 부여 (화염 — 지속피해 + **명확한 시각 변화**)
- [ ] 힐 스킬
- [ ] 자동 시전 토글

### 4주차 — 진행 구조
- [ ] 층 진행 (6층)
- [ ] 층 클리어 시 강화 3택 UI
- [ ] 런 내 강화 8종
- [ ] 보스 (6층)
- [ ] 소환 연출
- [ ] 사망 / 리트라이

### 5~6주차 — 검증
- [ ] 캐릭터 3명 전부 플레이 가능하게
- [ ] 밸런스 대충 맞추기
- [ ] **직접 20판 플레이. 재밌는지 판단**
- [ ] 외부인 3명에게 테스트
