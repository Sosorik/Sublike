# 현재 단계: Phase 1 — 프로토타입

**기간**: 4~6주 | **목표**: 재미 검증. 안 되면 여기서 갈아엎는다.

---

## 검증 질문 (이것만 확인)

1. **편성을 바꾸면 플레이가 재밌게 달라지는가?**
2. **버튼 3개 개입 타이밍이 실력으로 느껴지는가?**
3. **속성 부여가 화면에서 눈에 띄게 다른가?**
4. **컷인이 캐릭터를 매력적으로 보이게 하는가?**

3번과 4번이 특히 중요하다. 이 게임의 세일즈 포인트가 걸려 있다.

---

## 구현 범위

### 포함

| 항목 | 수량 | 비고 |
|---|---|---|
| 가신 | 3 | 전열1 / 중열1 / 후열1. 임시 아트 |
| 공격 타입 | 3 | 근접 / 단일사격 / 관통사격 |
| 아이다 스킬 | 3 | 버프1, 속성1(화염), 힐1 |
| 슬롯 | 3 | 전/중/후 각 1칸 |
| 층 | 6 | 1구간. 층당 웨이브 5 |
| 보스 | 1 | 6층 |
| 적 종류 | 3 | 돌격 / 사격 / 중갑 |
| 런 내 강화 | 8종 | 층 클리어 시 3택 |
| 컷인 | 1종 | 스킬 발동 연출 |
| 소환 연출 | 1 | 보스 격파 후 |

### 제외

- 가챠 재화 순환 / 영구 강화 / 세이브 / 로드
- 스토리 텍스트, 대사 (컷인 대사 1줄만)
- 심층도, 슬롯 확장
- UI 폴리싱, 사운드, 최종 아트

## 작업 순서

각 항목은 **실행 가능한 상태**로 끝내고 다음으로 넘어간다.

### 1주차 — 화면에 뭔가 나오게 하기
- [ ] Godot 프로젝트 초기화 (2D, Mobile 렌더러, 1280x720 가로)
- [ ] 씬 구조 안내 → 사용자가 에디터에서 생성
- [ ] **적 1마리가 오른쪽에서 왼쪽으로 걸어온다** ← 1주차 최소 목표
- [ ] 가신 1명이 제자리에서 자동 공격
- [ ] 적이 죽는다

> 이게 되면 게임의 뼈대가 선 것이다. 나머지는 살 붙이기.

### 2주차 — 전투 코어
- [ ] JSON 데이터 로더
- [ ] 오브젝트 풀
- [ ] 적 3종 (좌측 직진 AI)
- [ ] 웨이브 스포너
- [ ] 슬롯 3개 + 가신 3명 배치
- [ ] 공격 타입 3종
- [ ] DamagePacket 파이프라인
- [ ] 아이다 HP / 실패 처리

### 3주차 — 아이다 + 컷인
- [ ] 액티브 버튼 3개 UI + 쿨타임 게이지
- [ ] 버프 스킬
- [ ] **속성 부여 (화염) — 시각적 임팩트 최우선**
- [ ] 힐 스킬
- [ ] 자동 시전 토글
- [ ] **스킬 컷인 연출** (슬라이드 인 + 대사 + 플래시, 0.6초)

### 4주차 — 진행 구조
- [ ] 층 진행 (6층, 층당 웨이브 5)
- [ ] 층 클리어 시 강화 3택 UI
- [ ] 런 내 강화 8종
- [ ] 보스 (6층)
- [ ] 소환 연출
- [ ] 실패 / 리트라이

### 5~6주차 — 검증
- [ ] 가신 3명 편성 조합 테스트
- [ ] 밸런스 대충 맞추기
- [ ] **직접 20판 플레이. 재밌는지 판단**
- [ ] 외부인 3명 테스트
