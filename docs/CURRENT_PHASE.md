# 현재 단계: Phase 1 — 프로토타입

**기간**: 4~6주 | **목표**: 재미 검증. 안 되면 여기서 갈아엎는다.

---

## 검증 질문 (이것만 확인)

1. **편성과 배치를 바꾸면 플레이가 재밌게 달라지는가?**
2. **배치 타이밍과 버튼 3개 개입이 실력으로 느껴지는가?**
3. **속성 부여가 화면에서 눈에 띄게 다른가?**
4. **컷인이 캐릭터를 매력적으로 보이게 하는가?**

3번과 4번이 특히 중요하다. 이 게임의 세일즈 포인트가 걸려 있다.

---

## 구현 범위

### 포함

| 항목 | 수량 | 비고 |
|---|---|---|
| 가신 (손패) | **8** | 근접 5 / 원거리 3. 조합을 만들려면 타일 수보다 많아야 한다 |
| 배치 타일 | **9** | 레인3 × 열3. 지상 6 / 고지 3 |
| 동시 배치 | **6** | 타일보다 적게 — 다 채울 수 없어야 선택이 된다 |
| **DP** | — | 초당 1, 시작 10. 재배치 ×1.5→×2, 철수 환급 절반 |
| 공격 타입 | 3 | 근접 / 단일사격 / 관통사격 |
| 아이다 스킬 | 3 | 버프1, 속성1(화염), 힐1 |
| 층 | 6 | 1구간. 층당 웨이브 5 |
| 보스 | 1 | 6층 |
| 적 종류 | 3 | 돌격 / 사격 / 중갑 |
| 런 내 강화 | 8종 | 층 클리어 시 3택 |
| 컷인 | 1종 | 스킬 발동 연출 |
| 소환 연출 | 1 | 보스 격파 후 |

> **가신 3명·슬롯 3칸이던 이전 범위는 조합이 정확히 1가지였다.**
> 검증 질문 1번("편성을 바꾸면 재밌게 달라지는가")을 구조적으로 검증할 수 없었다.
> 손패 8명 · 타일 9칸 · 동시 배치 6명이라야 질문이 성립한다.

### 제외

- 가챠 재화 순환 / 영구 강화 / 세이브 / 로드
- 스토리 텍스트, 대사 (컷인 대사 1줄만)
- 심층도, 동시 배치 인원 확장, 시작 DP 강화
- 아이다 스킬 장착 교체 (데이터에 12종 있으나 Phase 1은 고정 3종)
- UI 폴리싱, 사운드, 최종 아트

## 작업 순서

각 항목은 **실행 가능한 상태**로 끝내고 다음으로 넘어간다.

### 1~4주차 — 완료

전투 코어, 아이다 스킬·컷인, 층 진행·강화 3택·보스·소환까지 끝났다.
상세는 `docs/PROGRESS.md`.

- [x] 데이터 로더 / 오브젝트 풀 / 적 3종 / 웨이브 스포너
- [x] 공격 타입 3종 / DamagePacket / 진군 차단 / 아이다 HP·실패
- [x] 액티브 3버튼 + 쿨타임 + 자동시전 / 버프·화염·힐 / 스킬 컷인
- [x] 층 진행 6층 / 강화 3택 + 런 강화 8종 / 보스 / 소환 연출 / 리트라이
- [x] 캐릭터 아트, 전투 연출(피해 숫자·파티클), 체력바

> **여기까지 만들고 나서 드러난 문제: 전투 중 플레이어가 할 게 버튼 3개뿐이다.**
> 편성은 전투 전에 고정되고 슬롯은 각 1칸이라 조합이 1가지였다.
> 레퍼런스인 명일방주의 핵심(전투 중 배치)이 통째로 빠져 있었다.

### 5주차 — DP 배치 시스템 (명일방주)

**이번 단계의 전부다. 이게 되면 비로소 전략이 생긴다.**

- [ ] 좌표 재편: 9타일 격자 (레인3 × 열3, 지상6 / 고지3)
- [ ] DP 자원 — 초당 1, 시작 10, HUD 표시
- [ ] 손패 UI — 가신 8명, 코스트 표시, DP 부족 시 비활성
- [ ] **배치** — 손패 선택 → 배치 가능 타일 강조 → 타일 선택 → 등장
- [ ] **철수** — 배치된 가신 선택 → 철수 → 코스트 절반 환급
- [ ] 재배치 코스트 상승 (×1.5 → ×2, 상한 99)
- [ ] 동시 배치 상한 6
- [ ] 근접=지상 / 원거리=고지 배치 제한
- [ ] 저지 0 가신은 근접 적이 지나침 (원거리 적에게는 맞음)
- [ ] 가신 8명 데이터 + 아트 (팩에서 추출)
- [ ] 힐 대상에 지상 가신 포함 (GDD 4.4)

### 6~7주차 — 검증

- [ ] **편성 조합 테스트** — 손패 8명에서 다른 조합으로 5판 이상
- [ ] 배치 순서·타이밍이 결과를 가르는지 확인
- [ ] 밸런스 대충 맞추기
- [ ] **직접 20판 플레이. 재밌는지 판단**
- [ ] 외부인 3명 테스트

## 완료 기준

> "한 판 더" 하고 싶은가?

이게 안 되면 아트를 아무리 잘 뽑아도 실패한다.

특히 **"아까는 이렇게 배치했는데 이번엔 다르게 해볼까"** 가 나와야 한다.
그게 안 나오면 배치 시스템을 넣고도 전략이 없는 것이다.
