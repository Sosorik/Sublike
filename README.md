# 웬델: 마석탑의 수문장

라인 방어형 오토배틀러 + 캐릭터 수집 + 로그라이트. 1인 개발.

## 시작 전 준비

1. **Godot 4 설치**
2. **공식 튜토리얼 "Your first 2D game" 완주** (2~3시간)
   → 노드 추가, 스크립트 연결, 씬 저장, F5 실행. 이것만 알면 된다.
3. 이 폴더를 프로젝트 루트로 열고 `claude` 실행

## 역할 분담

| 담당 | 작업 |
|---|---|
| **사용자** | Godot 에디터에서 `.tscn` 씬 생성, 실행/판단, 숫자 튜닝, 아트 선별 |
| **Claude** | `.gd` 스크립트, `.json` 데이터, 버그 수정 |

Claude는 씬 파일을 텍스트로 만들지 않는다. 대신 **클릭 단위로 안내**한다.

## 파일 지도

| 파일 | 역할 | 언제 |
|---|---|---|
| `CLAUDE.md` | 작업 규칙 | 자동 로드 |
| `GDD.md` | 전체 기획서 | 설계 판단 시 |
| `docs/CURRENT_PHASE.md` | **지금 만들 것** | 작업 전 항상 |
| `docs/ARCHITECTURE.md` | 씬 구조, 좌표 규약, 전투 파이프라인 | 구현 시 |
| `docs/SAVE_FORMAT.md` | 세이브 스키마 | 저장 작업 시 |
| `docs/PROGRESS.md` | 완료 기록 | 세션 시작/종료 |
| `docs/BACKLOG.md` | 범위 밖 아이디어 | 딴 생각 날 때 |
| `data/*.json` | 모든 수치 | 밸런싱 |
| `PROMPTS.md` | 복붙용 지시문 | 막힐 때 |

## 데이터 검증

```bash
python3 scripts/validate_data.py
```

가신/공격타입/스킬/층 참조 무결성 검사. **JSON 수정 후 항상 실행.**

## 핵심 원칙 4줄

1. `docs/CURRENT_PHASE.md`에 없으면 만들지 않는다
2. 수치는 코드가 아니라 `data/*.json`에
3. 유닛은 걷지 않는다. 화려함은 이펙트가 만든다
4. 1막이 완성되면 게임의 90%가 완성된 것이다
